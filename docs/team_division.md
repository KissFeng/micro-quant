## 汇报思路


### 1. 问题定义

我们关注的核心问题是：**能否利用机器学习和深度学习方法，从 A 股市场的历史数据中提取有效信号，构建一个具有正期望收益的量化选股策略？**

### 2. 数据与特征

我们从 Tushare 获取了 20 只 A 股蓝筹股的日线行情数据，并引入上证指数作为大盘特征。经过特征工程，我们构建了 38 个特征，涵盖：

- 动量特征（5/10/20 日涨跌幅）
- 波动率特征（收益率标准差）
- 成交量特征（量比、成交量均线）
- 技术指标（RSI、MACD、BBI）
- 大盘特征（指数动量、波动率、涨跌比）

标签方面，我们设定预测周期为 5 个交易日，阈值 2%——即未来 5 天涨幅超过 2% 视为"涨"，低于 -2% 视为"跌"，中间区域标记为模糊样本并排除，以过滤噪音。

```python
# 标签构建：三值分类，过滤噪音
future_return = df['Close'].shift(-horizon) / df['Close'] - 1
label = pd.Series(-1, index=df.index)       # 默认模糊
label[future_return > threshold] = 1         # 明确上涨
label[future_return < -threshold] = 0        # 明确下跌
# 中间区域保持 -1（训练时排除）
```

### 3. 模型设计

我们采用了三个模型的 AUC 加权集成方案：

- **LightGBM**：作为主力模型，擅长处理表格型特征，训练速度快，AUC 达到 0.554
- **CatBoost**：作为辅助模型，对类别特征有天然优势，AUC 为 0.522
- **LSTM**：捕捉时序依赖关系，AUC 为 0.510

![模型对比](../output/model_comparison.png)

模型核心参数配置：

```python
# LightGBM - 主力模型
LIGHTGBM_PARAMS = {
    'objective': 'binary',       # 二分类（关键修复项）
    'n_estimators': 200,
    'learning_rate': 0.1,
    'max_depth': 4,
    'num_leaves': 15,
    'subsample': 0.7,
    'colsample_bytree': 0.7,
    'reg_alpha': 0.1, 'reg_lambda': 0.1,
}

# LSTM - 时序模型
LSTM_PARAMS = {
    'seq_length': 5,             # 5天滑动窗口
    'lstm_units_1': 16,
    'lstm_units_2': 8,
    'dropout': 0.5,              # 强正则化防过拟合
    'learning_rate': 0.0005,
}
```

集成策略的关键设计：

- **弱模型过滤**：AUC < 0.52 的模型不参与预测，避免拖累整体
- **AUC 加权**：各模型按 AUC 大小分配权重，表现越好的模型话语权越大
- **反预测修复**：若某模型 AUC < 0.5，自动将概率取反（1 - prob）

```python
# AUC 加权集成核心逻辑
# 1. 跳过弱模型
effective_auc = max(model_auc, 1 - model_auc)
if effective_auc < 0.52:
    continue

# 2. 反预测修复
if model_auc < 0.5:
    prob = 1 - prob

# 3. AUC 加权求和
weights = {k: max(v, 0.01) for k, v in model_aucs.items()}
avg_prob = sum(model_probs[k] * weights[k] for k in model_probs) / sum(weights.values())
```

### 5. 关键优化历程

在开发过程中，我们经历了多轮迭代优化，系统从初始 AUC < 0.5、回测亏损 -15%，逐步优化至 AUC > 0.55、回测盈利 +6.35%：

1. **根因修复**：LightGBM 缺少 `objective='binary'`，导致 AUC < 0.5
   ```python
   # 修复前（回归模式，AUC < 0.5）
   LIGHTGBM_PARAMS = { 'n_estimators': 200, ... }
   # 修复后（二分类模式，AUC → 0.554）
   LIGHTGBM_PARAMS = { 'objective': 'binary', 'n_estimators': 200, ... }
   ```
2. **标签优化**：阈值从 0% 提升到 2%，过滤噪音样本
3. **集成策略**：从简单平均改为 AUC 加权，并加入弱模型过滤
4. **低频交易**：限制持仓周期和持仓数量，降低交易成本影响
5. **股票池扩展**：从 10 只扩展到 20 只，增加选股空间
