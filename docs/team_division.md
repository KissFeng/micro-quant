## 汇报思路

### 1. 实验背景

在 A 股市场的量化投资实践中，传统因子选股方法依赖人工经验构建因子体系，存在因子挖掘效率低、非线性关系捕捉不足、信号衰减快等问题。随着机器学习与深度学习技术的发展，基于数据驱动的智能选股方法逐渐成为量化研究的重要方向。传统机器学习模型（如 LightGBM、CatBoost）擅长处理表格型特征，训练速度快、可解释性强；深度学习模型（如 LSTM）能够捕捉时序依赖关系，挖掘隐藏模式。然而单一模型在复杂市场环境下容易过拟合或失效，多模型集成策略通过融合异构模型的优势，可有效提升预测稳健性。在当前 A 股市场对策略稳定性、风险控制及实盘可落地性提出更高要求的背景下，多模型集成量化选股方法的研究具有重要的理论与实践意义。

### 2. 实验原理

#### 机器学习模型

- **LightGBM**：基于梯度提升决策树的集成学习算法，采用 Leaf-wise 生长策略与直方图加速，擅长处理表格型特征，训练速度快，支持类别特征与缺失值处理
- **CatBoost**：基于有序提升（Ordered Boosting）的梯度提升算法，对类别特征有天然优势，内置过拟合防护机制，适合小数据集场景
- **LSTM**：长短期记忆网络，通过门控机制（遗忘门、输入门、输出门）捕捉时序依赖关系，适合处理金融时间序列数据

#### 集成策略

- **AUC 加权**：各模型按 AUC 大小分配权重，表现越好的模型话语权越大
- **弱模型过滤**：AUC < 0.52 的模型不参与预测，避免拖累整体
- **反预测修复**：若某模型 AUC < 0.5，自动将概率取反（1 - prob），修正反向预测问题

#### 回测验证

通过模拟真实交易环境（佣金、滑点、持仓周期约束），验证策略在样本外的盈利能力与风险特征，核心指标包括总收益率、夏普比率、最大回撤、胜率等。

### 3. 实验内容与步骤

#### 步骤 1：数据采集与特征工程

从 Tushare 获取 20 只 A 股蓝筹股的日线行情数据，并引入上证指数作为大盘特征。经过特征工程，构建 38 个特征：

- 动量特征（5/10/20 日涨跌幅）
- 波动率特征（收益率标准差）
- 成交量特征（量比、成交量均线）
- 技术指标（RSI、MACD、BBI）
- 大盘特征（指数动量、波动率、涨跌比）

标签构建：预测周期 5 个交易日，阈值 2%——未来 5 天涨幅超过 2% 视为"涨"，低于 -2% 视为"跌"，中间区域标记为模糊样本并排除，以过滤噪音。

```python
# 标签构建：三值分类，过滤噪音
future_return = df['Close'].shift(-horizon) / df['Close'] - 1
label = pd.Series(-1, index=df.index)       # 默认模糊
label[future_return > threshold] = 1         # 明确上涨
label[future_return < -threshold] = 0        # 明确下跌
# 中间区域保持 -1（训练时排除）
```

#### 步骤 3：AUC 加权集成

实现 AUC 加权集成策略，融合三个模型的预测概率：

```python
# AUC 加权集成核心逻辑
# 1. 跳过弱模型
effective_auc = max(model_auc, 1 - model_auc)
if effective_auc < 0.52:
    continue

# 2. 反预测修复
if model_auc < 0.5:
    prob = 1 - prob

# 3. AUC 加权求和
weights = {k: max(v, 0.01) for k, v in model_aucs.items()}
avg_prob = sum(model_probs[k] * weights[k] for k in model_probs) / sum(weights.values())
```

### 5. 实验分析与讨论

#### 实验成功点

1. 完整实现数据采集→特征工程→模型训练→集成预测→回测验证的全链路打通。
2. 多模型集成策略有效融合异构模型优势，AUC 加权 + 弱模型过滤 + 反预测修复三重保障提升预测稳健性。
3. 系统从初始 AUC < 0.5、回测亏损 -15%，优化至 AUC > 0.55、回测盈利 +6.35%。

#### 问题与解决

1. **LightGBM 缺少 `objective='binary'`**：导致模型以回归模式训练，AUC < 0.5；修复后 AUC → 0.554
   ```python
   # 修复前（回归模式，AUC < 0.5）
   LIGHTGBM_PARAMS = { 'n_estimators': 200, ... }
   # 修复后（二分类模式，AUC → 0.554）
   LIGHTGBM_PARAMS = { 'objective': 'binary', 'n_estimators': 200, ... }
   ```
2. **标签噪音干扰**：阈值从 0% 提升到 2%，过滤模糊样本，提升标签质量
3. **集成策略欠优**：从简单平均改为 AUC 加权，并加入弱模型过滤（AUC < 0.52 跳过）
4. **过度交易**：限制持仓周期（最低 5 天）和持仓数量（top 3），降低交易成本影响
5. **选股空间不足**：股票池从 10 只扩展到 20 只，增加选股空间

#### 优化方向

1. 引入更多特征（资金流向、北向数据、舆情），提升信息覆盖面
2. 尝试 Transformer 等更先进的时序模型，替代 LSTM
3. 加入风控模块（止损、仓位管理），控制尾部风险
4. 扩展到更多股票和更长回测周期，验证策略泛化能力

### 6. 实验结论

1. 多模型集成方法在 A 股市场具有可行性，系统从初始 AUC < 0.5、回测亏损 -15%，优化至 AUC > 0.55、回测盈利 +6.35%。
2. LightGBM 作为主力模型表现最优（AUC = 0.554），CatBoost 与 LSTM 作为辅助模型提供异构信号补充。
3. AUC 加权集成 + 弱模型过滤 + 反预测修复的三重机制有效提升预测稳健性。
4. 本系统可直接用于 A 股蓝筹股的量化选股、策略回测与信号推送等场景。
